# skillsplit

**Textrap** 팀 · 2026 하반기 SW·AI융합연구개발 일반과제 (한양대 ERICA SW중심대학사업단)

AI 에이전트 스킬(SKILL.md + 스크립트)의 악성 여부를 두 단계로 검사하고, **두 단계를 따로 돌려 각각 무엇을 잡고 무엇을 놓치는지 잰다.**

- **1단계** 정적 규칙: 스크립트와 설치 명령에서 위험 패턴을 정규식·AST로 탐지
- **2단계** LLM 판정: SKILL.md의 자연어 지시에서 프롬프트 인젝션·권한 상승 유도·사용자 은폐 지시를 판정

두 단계 결합은 새 방법이 아니다(SkillGate, SkillSieve, BIV 등). 이 저장소의 목적은 같은 질문을 **하나의 공개 벤치마크에서 실제/합성 샘플을 나눈 조건으로, 두 단계를 독립 실행해** 다시 묻는 것이다.

## 시작하기

처음이면 `docs/study-guide.md`부터 읽는다. 과제가 무엇이고 왜 하는지를 처음부터 끝까지 한 번에 읽는 글이고, 절마다 논문·기사 링크가 있다. 20분.

## 구조 (예정)

```
skillsplit/
  docs/            배경 자료, 결정 기록 요약
  skillsplit/      CLI와 두 단계 탐지기
  eval/            독립 실행 평가, 지표(PR-AUC, FPR 1% 재현율), 기준선 비교
  data/            벤치마크 내려받기·실제/합성 분리 스크립트 (데이터 자체는 커밋하지 않음)
```
